\subsection{General interface}


\paragraph{Preliminary steps}
Once the GA3 module opened, other windows cannot be opened, therefore
\begin{itemize}
  \item you will need to open the image you want to work with first,
  \item it is convenient to open the LUT tools first (\keys{\ctrl+\Alt+L}),
  \item opening the help  can also be useful.
\end{itemize}
To access the GA3 interface, you can either:
\begin{itemize}
  \item use the menu \menu{Image>New GA3 recipe\dots},
  \item use the menu \menu{Image>Analysis Explorer\dots} to open the analysis exporter and then click on \menu{Create New},
  \item right-click on the background of the interface, select \menu{Analysis Controls>Analysis Explorer} to open the analysis explorer and then click on \menu{Create New}.
\end{itemize}

\paragraph{Loading and saving recipes}

\begin{itemize}
  \item Use \menu{Save} or \menu{Save As} to save the recipe in the local database. It will be then listed in the Analysis Explorer.
  \item Use your name as a prefix so that we can contact you if the database needs to be cleared.
  \item Use \menu{Export} to export the recipe in a folder of your choice. This recipe can then be reloaded on another computer. It is good practice to have a copy of the recipes in that way.
  \item Use \menu{Import} to reload an exported recipe.
\end{itemize}

Recipes describe a workflow as a graph. The graph is composed of 4 types of nodes (See Fig.~\ref{fig:nodes}):
\begin{enumerate}\setlength\itemsep{0em}
  \item color: original or processed grayscale images
  \item action: processing steps on images, binary or tables
  \item binary: masks and labels
  \item results: tables with measurement results
\end{enumerate}

To add an action, drag the new element to the previous one to automatically create a connection and keep the elements organized. You can also use \keys{\shift} and left click circling the elements to select them. Finally, a group of elements can be combined to create a function.

\paragraph{Storing results}

Saving of channels and binary layers can be enabled case by case using a right click on the layer and selecting ``store this result'' or ``do not store this result''.

\subsection{Basic image processing concepts}

\paragraph{Image} An image is any array (table) of regularly sampled intensity values. The values can range between $0$ and $2^8 - 1 = 255$ for 8-bit images or between $0$ and $2^{16} - 1 = 65535$ for 16-bit images. Figure~\ref{fig:median} displays an image as graylevel and intensities values.

\paragraph{Threshold} Threshold is the simplest form of image segmentation. At each location of the image, a decision is taken to classify this point as foreground or background. In GA3, thresholds are followed by other operations such as smoothing, cleaning, connected component labelling, size filtering,\dots Here threshold are defined by a range with a minimum and maximum intensity. In fluorescence microscopy, we often want the minimum of this range to be more than 0 and the maximum untouched.

\paragraph{Median filter} The median filter is creating a new image where each pixel is computed as the median value of the pixels in a neighborhood of this pixel (See Figure~\ref{fig:median}). The median filter is a good approach for reducing the noise whilst preserving the edges of the image.

\paragraph{Morphological erosion and dilation} Erosion and dilation are morphological operations on the image. They can be expressed both for binary and grayscale images are the minimum and respectively maximum of the pixels in a neighborhood depicted in red in Figure.~\ref{fig:median}, \textit{i.e.} ranks 0 and 1. In practice, this neighborhood could have various shapes and also have a different weight. Formally, the erosion of an image $f$ at each pixel $x$ by a structuring element with weights $b$ defined as $(f \ominus b)(x) = \inf_{y} f(x+y) - b(y)$ and the dilation as $(f \oplus b)(x) = \sup_{y} f(y) + b(x-y)$. The result is an image with smaller, and respectively bigger, bright areas enabling to expand and shrink region.

\paragraph{Morphological opening and closing} Opening and closing are also morphological operations resulting of the combination an erosion followed by a dilation, and respectively, the dilation followed by an erosion. Formally, the opening is defined as $f \circ b  = (f \ominus b) \oplus b$ and the closing is defined as $f \bullet  b  = (f \oplus b) \ominus b$.

\paragraph{Rolling ball} Rolling ball~\cite{sternberg1983} is used for correcting shading and uneven background. It works by subtracting a background image estimated by a morphological opening of the image using a structuring element with radially decaying weights (the ball). As a rule of thumb, the ball radius must be set larger than the largest structural feature of interest, but smaller than the low-frequency illumination variation; otherwise, bright interior regions of large objects will be erroneously subtracted.

\paragraph{Watershed and distance transform} The watershed algorithm associates seed regions to pixels in the order of a priority map, analogous to flooding a topographic digital elevation model (DEM) (see Figure~\ref{fig:watershed}). In seeded watershed segmentation, separating touching objects often relies on computing the Euclidean Distance Transform (EDT) on a binary mask: $D(x) = \min_{y \in \text{Background}} \|x - y\|$. The EDT assigns to each foreground pixel its distance to the nearest boundary. Inverting this distance map transforms flat connected blobs into inverted cone-shaped basins, where local distance peaks serve as seeds to split touching cells along natural constrictions. In practice, algorithms such as ``priority-flood''~\cite{barnes2014} efficiently flood basins from these seeds using priority queues.

\paragraph{Spot detection} Sub-diffraction or punctate fluorescent signals (e.g., vesicles, endosomes, single molecules) approximate the microscope's point spread function (PSF). Detecting these puncta is commonly performed via band-pass scale-space filtering, such as Difference of Gaussians (DoG) or Laplacian of Gaussian (LoG). In GA3's \menu{Bright Spots} node, users specify a \textit{typical diameter} matching the expected optical PSF width and a \textit{contrast} threshold. The operator highlights local intensity maxima exceeding local background fluctuations, providing robust detection of diffraction-limited spots.

\paragraph{Particle tracking and linking} Tracking dynamic objects across time-series involves two distinct stages: (1) independent object or spot detection within each frame, and (2) temporal trajectory linking across consecutive frames. Trajectory linking associates centroids at frame $t$ with detections at frame $t+1$ by solving a linear assignment problem under maximum displacement constraints. In GA3, the standard deviation multiplicative factor defines an adaptive search radius based on observed Brownian displacement; detections outside this search radius initiate new tracks or are marked as terminated.

\paragraph{Pearson correlation coefficient and colocalization} The Pearson correlation coefficient (PCC)~\cite{pcc} measures the linear correlation between intensities of two channels $(r_i,g_i)$ across pixels $i$:
$$\mathrm{PCC} = \frac{\sum_i(r_i-\bar{r})(g_i-\bar{g})}{\sqrt{\sum_i(r_i-\bar{r})^2} \sqrt{\sum_i(g_i-\bar{g})^2}}$$
with means $\bar{r} = n^{-1}\sum_i r_i$ and $\bar{g} = n^{-1}\sum_i g_i$. Crucially, PCC must be computed within segmented regions of interest (mask-restricted colocalization). Calculating PCC across an entire unsegmented field of view is dominated by dark background pixels, generating misleading correlation artifacts.

\paragraph{Object parenting and relational tables} Quantifying spatial relationships (e.g., counting vesicles inside cells) establishes a 1-to-many hierarchical relationship: each parent cell contains $N$ child objects. In GA3, object parenting assigns a parent identifier (\textit{e.g.}, `CellID`) to each child record. Tabular aggregation nodes (\menu{Aggregate Rows}) can then compute per-parent summaries (\textit{e.g.}, `COUNT` of child spots, or `SUM` of child areas). Finally, relational operations such as \menu{Join Records} merge parent morphology tables with child aggregate tables using the common identifier (See Figure~\ref{fig:join}).

\paragraph{Deep learning vs.\ classical segmentation} Classical segmentation relies on manually tuned heuristics (intensity thresholds, morphological size filters, gradient edges). While computationally lightweight, these methods often fail in low signal-to-noise regimes, non-uniform staining, or dense tissue. Deep-learning approaches (such as NIS.ai \menu{segment.ai}, based on convolutional neural networks like U-Net) learn multi-scale contextual features directly from annotated training pairs (raw image $\leftrightarrow$ binary ground-truth). The model's generalization depends strictly on annotation fidelity: systematic annotation errors in the training set propagate directly into the trained network.



\subsection{Sample preparation and microscopy}

Lots of time can be saved by adjusting sample preparation and imaging to match existing  analysis tools.

\paragraph{Housekeeping labels} If possible, and when aiming at cell level statistics, include extra labels that will help identify cells location during sample preparation. A DNA stain such as DAPI or Hoechst and a plasma membrane marker such as WGA, Invitrogen's CellMask or Biotium's CellBrite can be used for example.

\paragraph{Cell confluence} Depending on the type of analysis workflow and the cell line, high cell confluence can be counterproductive as cell will tend to grow on top of each other.

\paragraph{Dataset size} When acquiring data, have in mind the scale of the process you want to capture. If only a fraction of the cells are of interest, define multiple position instead of tiling a large field of view at high resolution will reduce the size of the dataset.
