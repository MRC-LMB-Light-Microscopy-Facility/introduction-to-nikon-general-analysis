\paragraph{Objectives}
By the end of this workshop, participants will be able to:
\begin{itemize}
  \item Construct automated analysis pipelines (recipes) in GA3 by assembling preprocessing, segmentation, and measurement nodes to accurately quantify microscopy images.
  \item  Implement advanced segmentation strategies, such as seeded watershed and intensity thresholding, to identify structures and separate touching objects.
  \item  Quantify spatial and hierarchical relationships between biological structures using object parenting, colocalization metrics, and relational table operations (joins and aggregations).
  \item  Track moving objects over time-series data to extract dynamic kinematic parameters, including positions, trajectories, and velocities.
  \item  Train and deploy deep-learning models with NIS.ai to automate segmentation tasks that are challenging for traditional thresholding.
  \item  Export and manage analysis outputs, saving measurements and binary masks according to reproducible data-handling practices.
  \item Automate high-throughput processing by executing batch GA3 workflows across multi-image datasets independently.

\end{itemize}
