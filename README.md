# Introduction to Nikon NIS General Analysis module.

This repository contains the latex code of the support material for the training on the NIS module General Analysis from Nikon.

This training is geared towards a problem-solving oriented approach with an introduction to the basic required topics.

## Learning Objectives

By the end of this course, participants will be able to:

- **Construct automated analysis pipelines (recipes)** in GA3 by assembling preprocessing, segmentation, and measurement nodes to accurately quantify microscopy images.
- **Implement advanced segmentation strategies**, such as seeded watershed and intensity thresholding, to identify structures and separate touching objects.
- **Quantify spatial and hierarchical relationships** between biological structures using object parenting, colocalization metrics, and relational table operations (joins and aggregations).
- **Track moving objects over time-series data** to extract dynamic kinematic parameters, including positions, trajectories, and velocities.
- **Train and deploy deep-learning models** with NIS.ai to automate segmentation tasks that are challenging for traditional thresholding.
- **Export and manage analysis outputs**, saving measurements and binary masks according to reproducible data-handling practices.
- **Automate high-throughput processing** by executing batch GA3 workflows across multi-image datasets independently.
